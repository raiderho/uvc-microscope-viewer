# 測試狀態與新型號回報

## 已有證據

- Windows 11 x64，Windows PowerShell 5.1。
- TN2.0M-D，VID/PID `055E:A165`，Microsoft `usbvideo` 功能驅動。
- 原始入口已實機驗證 MJPEG 1920×1080、YUY2 640×480 的單張擷取；預覽、拍照及恢復預覽成功。
- 改為通用版後的離線測試已通過 23 項，涵蓋設定保存、相對與絕對路徑、參數引號、不同裝置名稱、禁止注入音訊輸入、雜湊不符拒絕、相互排斥鎖，以及不把其他程序誤認為本程式的預覽。
- 隨程式資料夾的工具配置與雜湊檢查已通過，不再引用原電腦的固定安裝路徑。
- 通用版命令列入口已再次完成 1920×1080 PNG 擷取與預覽恢復；已實際觀察到資料夾內 FFplay 開啟的影像視窗。
- 含空白的自訂照片子資料夾已實際拍照成功，PNG 為 1920×1080，預覽正常恢復；測試後已將本機設定還原為預設 photos。

控制面板程式已走到開啟視窗的階段，但本次自動化工具未列出 PowerShell 所承載的 Windows Forms 視窗，因此**尚未完成控制面板逐鍵點選及顯示配置的人工驗收**。核心動作的成功結果不能代替這項 UI 驗收；之後可用下方表格補測。

測試輸出、影像及個人路徑不公開提交；本地留在 `runtime`／`photos` 等忽略目錄。
