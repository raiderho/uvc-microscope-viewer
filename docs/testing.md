# 測試狀態與新型號回報

## 2026-11-15：Windows Media Foundation 輕量版

平台：Windows 11 x64、Windows PowerShell 5.1、系統 .NET Framework 編譯器。
裝置：TN2.0M-D，VID/PID `055E:A165`，Microsoft `usbvideo` 功能驅動。

已完成：

- C# 原始碼本機編譯，執行檔約 30 KiB，沒有 NuGet、FFmpeg／FFplay 或額外影音 DLL。
- 27 項離線檢查：設定保存、路徑與引號、輸入限制、動作互斥、乾淨資料夾自動編譯、雜湊與異動產物拒絕、不接管其他程序。
- 原生影像自測：RGB 通道、正負 stride、上下方向、每列 padding、PNG 往返、截斷與過大 buffer 拒絕。
- Windows Media Foundation 列出目鏡及格式；MJPEG 1920×1080／30 fps、YUY2 640×480／30 fps 拍照成功，PNG 尺寸與格式已驗證。
- 實際看見新版預覽及影像，點選「拍照（PNG）」後存檔成功；「查看照片」開啟指定資料夾。
- CMD 核心流程完成預覽、拍照、恢復預覽、停止；以新程序啟動時間驗證恢復。
- 含空白的自訂照片路徑存檔成功。硬體測試使用獨立設定檔，不變更個人 settings.json。

重跑指令見 [README](../README.md#開發與重跑測試)。測試腳本會清理暫存照片與設定；使用者照片保留，個人資料不公開提交。

## 舊版本及未完成項目

舊 FFmpeg 版曾通過 23 項離線檢查及相同目鏡的擷取。這次已重新實測替換後流程，不沿用舊結果當成新版證據。

PowerShell 控制面板及設定對話框仍未逐一人工驗收；新 C# 預覽視窗的拍照與查看照片已實際操作。

尚未驗證其他型號、Windows 10 實機、Windows N、ARM、macOS、Linux、Android／iPad、長時間零掉幀、USB 拔插復原、顯微樣本解析力、色彩校正或量測精度。
